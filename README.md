# Flashloan Arbitrage Bot

A GUI-based flashloan arbitrage bot built with Python and Node.js. This bot allows you to run Ethereum-based arbitrage operations while monitoring logs in real-time.

---

## Features

- Modern Tkinter GUI for ETH amount input and log monitoring  
- Real-time log output with color support  
- Start/Stop controls for the bot  
- Environment-based configuration for secure private keys and RPC URLs
